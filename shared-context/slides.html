Memory that reasons

concepts from Honcho by Plastic Labs, honcho.dev (AGPL-3.0)

Honcho's ideaWhat the Brain carries

Peers: users and agents are both peers

Every person and every agent signs as a peer on one mesh

Sessions and messages

Signed messages in threads, addressed, copied, or broadcast

Dreaming: reasoning in the background

Related messages get linked and threads summarized in the background

context(): curated context, not the whole history

Each delivery carries one line of graph context

The model is simple: peers, memory, reasoning over it. The Brain gives a whole team one shared memory without claiming who uses it.
